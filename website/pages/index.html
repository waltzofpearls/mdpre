Markdown Preview

A markdown preview app for developers. Edit, listen, and watch your files reload as you work.

Download for macOS

Free, no accounts, no tracking. Requires macOS 15.7 or later.
The direct download (.dmg) keeps itself up to date.

What it does

  • Light editing with syntax highlighting and a formatting toolbar.
  • Side by side editor and preview, with synchronized scrolling.
  • Text to speech that reads the document, highlighting each word as it goes.
  • Live reload that refreshes automatically when files change in any editor.
  • GitHub Flavored Markdown rendered with syntax highlighting.
  • Folder mode with a sidebar for browsing markdown directories.
  • A bundled CLI tool so mdp README.md opens a file from the terminal.
  • Export as PDF or HTML, or print.
  • Find in document, a table of contents, and light or dark appearance.
