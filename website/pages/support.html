Common questions

How do I use the mdp command?

Choose Markdown Preview > Install Command Line Tool... from the menu bar and authorize it. Then mdp README.md opens a file, mdp docs/ opens a folder, and mdp --version shows the version.

Why is it asking for permission to read a folder?

In the Mac App Store version, the command line tool runs in a sandbox and cannot hand file access to the app. The first time you open a document from a folder, the app asks for permission to read that folder. Grant it once and files in that folder open without prompting afterwards. The direct download version (.dmg) never asks.

Which version should I install?

They have the same features. The Mac App Store version updates through the App Store. The direct download version (.dmg) updates itself and does not require an Apple account.

Does it edit files, or only preview them?

Both. It opens in preview mode, and the Edit and Split modes give you an editor with a formatting toolbar. When you open a single file, edits are saved automatically. In folder mode, save with Cmd+S, and you are prompted about unsaved changes before closing.

My images are not showing.

Images referenced with relative paths need read access to the folder containing the document. The app asks for permission the first time, and once you grant it, images in that folder load without prompting again.
